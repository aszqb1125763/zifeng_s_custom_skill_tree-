# Zifeng Skill Tree（子枫的百宝箱）

一个基于 **Minecraft 1.20.1（Forge）/ 1.21.1（NeoForge）** 的 Minecraft 技能树模组：通过星能转换机把 FE 能量转化为技能点，在技能树界面中解锁技能（魔法 / 基础 / 增幅 / 终极 / 特殊被动 / 光环 / 寰宇法则 / 机械共鸣 / 子枫的馈赠），并利用多余电力获得全方位战斗与生存强化。

> 💡 本模组由技术区 YouTube/B站 博主 **子枫**（不无聊的子枫哥）创作，代码由 **AI 辅助开发**，并完全开源（MIT）。

## ✨ 功能特性

- **技能树界面**：按 `N` 键打开（标题「子枫的百宝箱」），**九列技能布局**（魔法增幅 → 基础 → 增幅 → 终极 → 特殊被动 → 光环 → 寰宇法则 → 机械共鸣 → 子枫的馈赠），顶部对齐
- **114 种技能（全部带子枫个人特色的名字）**：
  - **魔法增幅（15 种）**：聚元心法/回灵吐纳（新生魔艺）、铁元聚灵/铁元回灵/疾咏之术/法脉通达（铁魔法）、焚天烈焰/寒冰刺骨/九霄雷动/圣光降临/虚空遁形/血祭狂潮/百灵听令/自然之息/异界低语（9 流派）——需安装对应模组才生效（未安装显示红字提示）
  - **基础属性（16 种）**：血魄淬炼、铁壁金身、磐石之躯、剑心通明、疾风连击、破岩神工、健步如飞、生生不息、鸿运当头、一蹦三尺、御空翱翔、如鱼得水、暴击要害、噬血之刃、荆棘护体、破甲利刃
  - **特殊增幅（16 种）**：与基础一一对应的「X真解」系列（统一公式：基础 × (1 + 增幅)）
  - **终极节点（15 种）**：子枫的燃血狂战、子枫的金刚不坏、子枫的全能精通、子枫的苍穹之翼（真创造飞行）、星瞳夜视、饱食无忧、子枫的浴火重生、死神凝视、子枫的虚空神体（三层无敌防御）、御风止步（无飞行惯性）、凌空采掘（飞行挖掘）、烈焰不侵（免疫火焰）、鲛人之息（水下呼吸）、破暗之瞳（免疫黑暗）、碧波清眸（水下视野）
  - **特殊被动（21 种）**：万民敬仰、长臂善舞、星光点缀、财源滚滚（掉落翻倍）、万载不磨、猎魂丰收、点石成金、经验飞涨、妖魂凝卵、斩首夺颅、自动熔炼术、**子枫的万物可掘（持镐挖基岩）**、**不朽铭文（铁砧合成无法破坏工具）**、**横扫千军（龙研式 100° 扇形 AOE）**、**稳如泰山（满级免疫击退）**、随机附魔、附魔突破、超限附魔（铁砧附魔系列）、无限交易、村民大师、寻宝大师（64 格透视）
  - **光环（8 种）**：子枫的杀戮领域（伤害）、疾攻之势（速度）、回春妙手（治愈）、吸星大法（磁力）、子枫的修罗杀域（强化·混沌/Boss伤害）、定身神域（免疫TP/击退）、子枫的虚空诛灭（绝对秒杀+攻击范围50格+磁铁范围55格）、**子枫挪移术（木棍绑定容器，掉落直传不生成实体，刷怪塔不卡顿）**
  - **寰宇法则（3 种，全局列）**：**时之环·刹那永恒**（锁时间）、**晴空环·艳阳高照**（锁晴天，第二快捷键切换 ☀/🌧/⛈）、**无限回路**（AE2 频道 2×/3×/4×/无限 4 级）——服务器全局生效，事件驱动零轮询同步，技能树 tooltip 实时显示服务器当前状态
  - **机械共鸣（9 种）**：机关道祖（1000 点，无前置）+ 8 共鸣技能（各 5000 点）：财源滚滚/万载不磨/猎魂丰收/点石成金/经验飞涨/妖魂凝卵/斩首夺颅/自动熔炼·机关共鸣。学习并开启后，模拟玩家机器（如数字型采矿机）才能继承对应效果，关闭/重置立即回收
  - **子枫的馈赠（11 种）**：时间洗礼/风暴/洪流（保底：游戏 1/5/10 小时激活，每 10/5/1 分钟 +1/5/10 点）+ 移动/飞行/挖掘/击杀洗礼（1-5 级：1000/500/100/50/10 触发，消耗 10/1000/10000/50000/100000）+ 4 增幅（上限 5 级，每级每次 +1 点，30% 指数消耗）。只对真玩家生效，免费获得技能点
- **🚫 自动熔炼黑名单**：手持【熔炼产物】输入 `/hmd` 加入黑名单（无需作弊权限），`/delhmd` 查看移除；按熔炼产物匹配，不同模组同类矿通用（手持铁锭→所有模组铁矿石/粗铁不熔炼）
- **星能转换机**：1 亿 FE = 1 技能点，阶梯消耗（前 2000 点玩家级共享折扣）、进度条显示，跨维度共享玩家累计；输入速率可调、无限制模式开关、Jade 64 位能量显示
- **⚠️ 发电提示**：本模组**不自带发电**，需要配合一个能产生 FE 能量的科技模组（如 Mekanism、龙之研究、AE2）为星能转换机供电
- **⚔️ 混沌守卫击杀**：光环攻击可击杀龙之研究（Draconic Evolution）混沌守卫与水晶（混沌伤害 + 连击破盾，对所有 Boss 生效）
- **🛡 光环锁定**：开启后免疫一切传送（/tp、传送门、末影珍珠）与击退，纯事件驱动零卡顿
- **🌟 星空环视觉**：玩家脚下末地传送门动态星空环（第三人称可见），内圈描边 + 外圈渐变
- **属性面板**：右下角开关按钮，实时显示全部属性（Shift+点击可切换面板布局）
- **技能点 HUD**（左下角）：绿色总数常驻固定位置，各来源行平滑滑入+缩放+淡出动画，转换机速率显示；HUD 面板可开关、可调位置（点击 ±1 / Shift ±10 / Ctrl ±100，X ±800 / Y ±400，一键重置归零，位置持久化）
- **掉落增幅**：只对原版时运/抢夺适用的掉落生效（挖矿翻倍、杀怪掉率提升），与原版时运叠加
- **多人支持**：数据按玩家独立存储（主世界 SavedData），多玩家计数正确恢复；全局技能订阅界面驱动推送（打开技能树订阅、关闭取消，增量包+快照去重，零轮询）
- **配置热重载**：全部核心数值走 `Config.java`，游戏内即可调整
- **高性能**：光环攻击间隔制（默认 10 秒/次）、锁定纯事件驱动、转换机 20 tick 阈值缓存、AE 反射成员缓存、兼容 Iris 光影

## 🎮 游戏内操作

| 操作 | 功能 |
| --- | --- |
| `N` | 打开技能树 |
| 左键点击技能 | 加 1 级 |
| `Shift`+左键 | 一次加 10 级 |
| `Ctrl`+`Shift`+左键 | 一次加 100 级 |
| 右键点击技能 | 切换技能开关（光环技能 Shift+右键切换目标模式）|
| 滚轮悬停技能 | 调整生效等级 |
| `Ctrl`+`R` | 重置鼠标悬停的技能（按返还率退点）|
| `/hmd` | 手持【熔炼产物】加入自动熔炼黑名单（无需作弊权限）|
| `/delhmd` | 查看并移除黑名单 |

### 技能双快捷键（技能树内绑定）

- 每个技能按钮右侧有两列快捷键框：**开关（⚡）** + **等级/目标循环**（光环 🎯 / 其他 📶）
- 点击按键框进入绑定，按任意键设置；退格键/删除键清空绑定
- 等级循环步进：按键 +1 / `Shift` +10 / `Ctrl`+`Shift` +100 / **`Alt` 反向**
- 光环目标模式独立：伤害/速度/治愈各有自己的 敌对/友好/所有 过滤（不再共用）
- 调整生效等级/目标模式时聊天栏提示（📶/🎯）
