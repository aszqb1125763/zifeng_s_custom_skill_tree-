# 子枫的自定义技能树 (zifeng_s custom skill tree)

一个基于 **NeoForge 1.21.1** 的 Minecraft 技能树模组：通过星能转换机把 FE 能量转化为技能点，在技能树界面中解锁技能（基础 / 增幅 / 终极 / 杀戮光环），并利用多余电力获得全方位战斗与生存强化。

> 💡 本模组由技术区 YouTube 博主 **子枫** 创作，代码由 **AI 辅助开发**，并完全开源（MIT）。

![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-green) ![NeoForge](https://img.shields.io/badge/NeoForge-21.1.248-orange) ![License](https://img.shields.io/badge/License-MIT-blue)

## ✨ 功能特性

- **技能树界面**：按 `N` 键打开，四列技能布局（基础 → 增幅 → 终极 → 光环），顶部对齐
- **54 种技能**：
  - **基础属性（16 种）**：生命强化、体魄强化、坚韧之躯、锋刃精通、疾攻术、采掘熟稔、疾行步法、再生体魄、幸运眷顾、跃升体术、御空术、潜游术、暴击精通、生命汲取、荆棘反伤、破甲精通
  - **特殊增幅（17 种）**：与基础一一对应 + 掉落增幅（统一公式：基础 × (1 + 增幅)）
  - **终极节点（13 种）**：浴血奋战（攻+50%/命+50%）、不坏金身（抗性10/吸收100/抗火5）、全能精通（全方位防御）、宇宙的青睐（真创造飞行）、星瞳·夜视、星食·饱腹、凤凰涅槃（1分钟复活+冷却图标）、死神凝视（处决）、**虚空之躯（三层无敌防御）**、**村庄英雄（10级，每级+4级英雄效果）**、**接触距离（50级，每级+1格触摸/攻击距离）**、**发光（35格半径生物发光）**、**战利品爆炸（100级，击杀掉落翻倍，原版自然落地）**
  - **光环（8 种）**：杀戮光环·伤害、杀戮光环·速度、治愈光环、磁力光环、时之环·永恒正午、晴空环·永恒晴天、光环锁定（免疫TP/击退）、**杀戮光环·虚空之矛（绝对秒杀+攻击范围50格+磁铁范围55格）**
- **星能转换机**：1 亿 FE = 1 技能点，阶梯消耗、进度条显示，跨维度共享玩家累计
- **⚔️ 混沌守卫击杀**：光环攻击可击杀龙之研究（Draconic Evolution）混沌守卫与水晶（混沌伤害 + 连击破盾，对所有 Boss 生效）
- **🛡 光环锁定**：开启后免疫一切传送（/tp、传送门、末影珍珠）与击退，纯事件驱动零卡顿
- **🌟 星空环视觉**：玩家脚下末地传送门动态星空环（第三人称可见），内圈描边 + 外圈渐变
- **属性面板**：右下角开关按钮，实时显示全部属性（Shift+点击可切换面板布局）
- **掉落增幅**：只对原版时运/抢夺适用的掉落生效（挖矿翻倍、杀怪掉率提升），与原版时运叠加
- **多人支持**：数据按玩家独立存储（主世界 SavedData），多玩家计数正确恢复
- **配置热重载**：全部核心数值走 `Config.java`，游戏内即可调整
- **高性能**：光环攻击间隔制（默认 10 秒/次）、锁定纯事件驱动、兼容 Iris 光影
