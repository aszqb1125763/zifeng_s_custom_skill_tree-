# Zifeng Skill Tree（子枫技能树）

一个基于 **NeoForge 1.21.1** 的 Minecraft 技能树模组：通过星能转换机把 FE 能量转化为技能点，在技能树界面中解锁技能（基础 / 增幅 / 终极 / 杀戮光环），并利用多余电力获得全方位战斗与生存强化。

> 💡 本模组由技术区 YouTube 博主 **子枫** 创作，代码由 **AI 辅助开发**，并完全开源（MIT）。

## ✨ 功能特性

- **技能树界面**：按 `N` 键打开，**六列技能布局**（魔法增幅 → 基础 → 增幅 → 终极 → 光环 → 机械共鸣），顶部对齐
- **88 种技能**：
  - **魔法增幅（14 种）**：新生魔艺魔力增幅/恢复、铁魔法魔力增幅/恢复/吟唱缩减/冷却缩减、9 流派法术强度（火焰/冰霜/雷电/神圣/末影/鲜血/召唤/自然/异界）——需安装对应模组才生效（未安装显示红字提示）
  - **基础属性（16 种）**：生命强化、体魄强化、坚韧之躯、锋刃精通、疾攻术、采掘熟稔、疾行步法、再生体魄、幸运眷顾、跃升体术、御空术、潜游术、暴击精通、生命汲取、荆棘反伤、破甲精通
  - **特殊增幅（16 种）**：与基础一一对应（统一公式：基础 × (1 + 增幅)）
  - **终极节点（24 种）**：浴血奋战、不坏金身、全能精通、宇宙的青睐（真创造飞行）、星瞳·夜视、星食·饱腹、凤凰涅槃、死神凝视、虚空之躯（三层无敌防御）、村庄英雄、接触距离、发光、战利品爆炸（掉落翻倍）、工具不毁、生物掉落、方块掉落、经验获取、刷怪蛋掉落、怪物头颅掉落、自动熔炼（按熔炉配方自动熔炼掉落物）、**万物挖掘（持镐挖基岩等不可破坏方块）**、**不毁词条（铁砧合成无法破坏工具）**、**横扫范围（龙研式 100° 扇形 AOE）**、**击退抗性（满级免疫击退）**
  - **光环（9 种）**：杀戮光环·伤害、杀戮光环·速度、治愈光环、磁力光环、时之环·永恒正午、晴空环·永恒晴天、杀戮光环·强化（混沌/Boss伤害）、光环锁定（免疫TP/击退）、杀戮光环·虚空之矛（绝对秒杀+攻击范围50格+磁铁范围55格）
  - **机械共鸣（9 种）**：机械之星（1000 点，无前置）+ 8 共鸣技能（各 5000 点）：战利品爆炸/工具不毁/生物掉落/方块掉落/经验获取/刷怪蛋/头颅/自动熔炼·共鸣。学习并开启后，模拟玩家机器（如数字型采矿机）才能继承对应效果，关闭/重置立即回收
- **🚫 自动熔炼黑名单**：手持物品输入 `/hmd` 加入黑名单（无需作弊权限），`/delhmd <id>` 移除（Tab 只补全黑名单已有 id）；黑名单中的物品不参与熔炼判定，当正常方块掉落
- **星能转换机**：1 亿 FE = 1 技能点，阶梯消耗、进度条显示，跨维度共享玩家累计；输入速率可调、无限制模式开关、Jade 64 位能量显示
- **⚠️ 发电提示**：本模组**不自带发电**，需要配合一个能产生 FE 能量的科技模组（如 Mekanism、龙之研究、AE2）为星能转换机供电
- **⚔️ 混沌守卫击杀**：光环攻击可击杀龙之研究（Draconic Evolution）混沌守卫与水晶（混沌伤害 + 连击破盾，对所有 Boss 生效）
- **🛡 光环锁定**：开启后免疫一切传送（/tp、传送门、末影珍珠）与击退，纯事件驱动零卡顿
- **🌟 星空环视觉**：玩家脚下末地传送门动态星空环（第三人称可见），内圈描边 + 外圈渐变
- **属性面板**：右下角开关按钮，实时显示全部属性（Shift+点击可切换面板布局）
- **掉落增幅**：只对原版时运/抢夺适用的掉落生效（挖矿翻倍、杀怪掉率提升），与原版时运叠加
- **多人支持**：数据按玩家独立存储（主世界 SavedData），多玩家计数正确恢复
- **配置热重载**：全部核心数值走 `Config.java`，游戏内即可调整
- **高性能**：光环攻击间隔制（默认 10 秒/次）、锁定纯事件驱动、兼容 Iris 光影

## 🎮 游戏内操作

| 操作 | 功能 |
| --- | --- |
| `N` | 打开技能树 |
| 左键点击技能 | 加 1 级 |
| `Shift`+左键 | 一次加 10 级 |
| `Ctrl`+`Shift`+左键 | 一次加 100 级 |
| 右键点击技能 | 切换技能开关（光环技能 Shift+右键切换目标模式）|
| 滚轮悬停技能 | 调整生效等级 |
| `Ctrl`+`R` | 重置鼠标悬停的技能（按返还率退点）|
| `/hmd` | 手持物品加入自动熔炼黑名单（无需作弊权限）|
| `/delhmd <id>` | 从黑名单移除（Tab 只补全黑名单已有 id）|
