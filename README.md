# 子枫的自定义技能树 (zifeng_s custom skill tree)

一个基于 **NeoForge 1.21.1** 的 Minecraft 技能树模组：通过星能转换机把 FE 能量转化为技能点，在技能树界面中解锁 32 种技能（基础 / 增幅 / 终极 / 杀戮光环）。

> 💡 本模组由技术区 YouTube 博主 **子枫** 创作，代码由 **AI 辅助开发**，并完全开源（MIT）。

## ✨ 功能特性

- **技能树界面**：按 `N` 键打开，四列技能布局（基础 → 增幅 → 终极 → 杀戮光环），自动居中适应屏幕
- **32 种技能**：
  - **基础属性（11 种）**：体魄强化、坚韧之躯、锋刃精通、疾攻术、采掘熟稔、疾行步法、再生体魄、幸运眷顾、跃升体术、御空术、潜游术
  - **特殊增幅（10 种）**：战斗强化、攻速增幅、采掘效率、生命涌泉、防御强化、移速增幅、掉落增幅、跃升增幅、御空增幅、潜游增幅（统一公式：基础 × (1 + 增幅)）
  - **终极节点（8 种）**：浴血奋战、疾风连斩、不坏金身、万物皆可挖、全能精通、宇宙的青睐（真创造飞行）、夜视、饱食
  - **杀戮光环（3 种）**：杀戮光环·伤害、杀戮光环·武器、杀戮光环·速度（范围伤害 + 特效圆环）
- **星能转换机**：1 亿 FE = 1 技能点，阶梯消耗、进度条显示，支持跨维度共享玩家累计
- **属性面板**：右下角开关按钮，实时显示全部属性（Shift+点击可切换面板布局）
- **掉落增幅**：只对原版时运/抢夺适用的掉落生效（挖矿翻倍、杀怪掉率提升），与原版时运叠加
- **多人支持**：数据按玩家独立存储（主世界 SavedData），多玩家计数正确恢复
- **配置热重载**：全部核心数值走 `Config.java`（economy / aura / ultimate / newSkills 四组），游戏内即可调整
